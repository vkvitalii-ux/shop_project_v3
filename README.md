# Магазин электроники (shop_project)

Проект представляет собой базовую модель интернет-магазина, написанную на Python.

## Реализованный функционал
- **Класс `Product`**: хранит информацию о товаре (название, описание, цена, остаток на складе).
- **Класс `Category`**: объединяет товары в категории (название, описание, список товаров).
- **Автоматический подсчет**: система автоматически считает общее количество категорий и количество уникальных товаров по их имени.

## Тестирование и качество кода
- Написаны unit-тесты с использованием `pytest`.
- Покрытие кода тестами составляет **100%** (используется `pytest-cov`).

- Код полностью проверен линтером `flake8` на соответствие стандартам PEP 8.


## Новая функциональность

* Добавлены классы-наследники для смартфонов (Smartphone) и газонной травы (LawnGrass).
* Реализована строгая проверка типов при сложении продуктов (функция type).
* Реализована валидация при добавлении товаров в категорию (функция isinstance).


## Дополнительная функциональность

### Абстрактные классы и миксины
В проекте реализован абстрактный базовый класс `BaseProduct` (или `MixinLog`, укажите точное название вашего класса/миксина), который задает обязательный интерфейс для всех продуктов и обеспечивает логирование процесса создания объектов (вывод в консоль информации о созданном объекте и его параметрах).

### Отчет о покрытии тестами (Coverage)
Для проверки работоспособности кода и фиксации покрытия проекта тестами используется плагин `pytest-cov`.

**Запуск тестов с генерацией HTML-отчета:**
```bash
pytest --cov=. --cov-report=html
```
После запуска команды актуальный отчет формируется в папке `htmlcov/` в корне проекта.
